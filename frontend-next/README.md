# Northstar Next.js frontend

An isolated Next.js App Router implementation for the Spring Boot job portal. It uses strict TypeScript, Tailwind CSS 4, Radix/shadcn-style primitives, TanStack Query, Zustand, React Hook Form, Zod, Sonner, and Lucide React.

See [ARCHITECTURE.md](./ARCHITECTURE.md) for the module map, state boundaries, API assumptions, production integration gaps, and the development command.

```powershell
npm install
npm run dev
```
